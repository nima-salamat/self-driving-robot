Exit Stream?
Stop the web dashboard server

    

      
This stops the Stream HTTP server and sets STREAM=False in the current process, like running without --stream. The robot’s main City/Race loop, perception, and motion control keep running. This does not stop the robot.

      
Once stopped, this dashboard will disconnect. To open it again, restart the program with --stream.

      

    

    

  






  

    
Editor Settings
Grid, snapping, stream display rate, and ROI appearance

    
Grid & Snap

      
      
      
      
      
      
      
      
      
Grid spacing is measured relative to image height; horizontal spacing is corrected for the frame aspect ratio so grid cells remain square. Arrow keys move the selected ROI by the configured number of source-image pixels; Shift + Arrow moves 5× farther.

    

    
Stream Display Performance

      
      
Controls how often this page requests a new frame. It is separate from target processing FPS and the camera sensor FPS; the actual display rate can be lower when frames, network, or browser rendering are slower.

      
      
Lower quality generally reduces image size and network bandwidth; higher quality preserves more detail. This only changes JPEG encoding for dashboard frames—not camera resolution, sensor FPS, or the robot's vision/control processing. Changing it requires dashboard controls to be enabled.

    

    
ROI Appearance

      
      
      
      
      
Appearance values are base sizes at 100% zoom; overlays scale with the camera image.

Crosswalk Line-count Thresholds

      
The detector checks how many vertical and horizontal line segments appear in the crosswalk region, then performs its existing lowest-horizontal-line position check. Defaults preserve the current condition: at least 6 vertical and 3 horizontal lines.

Command Format Help

      
f = forward, b = reverse. Then give PWM (0–255), encoder pulse count (1–10000), and servo angle (0–180°).

      
Every motion command has four whitespace-separated tokens. Append another group to continue. Example: f 220 80 95 f 220 80 120.

      
Saving validates token groups, directions and numeric ranges. It cannot determine whether a maneuver is physically safe, so test in a clear controlled area with wheels lifted when appropriate.

    

    

  






  

    
{{ mode|capitalize }} · PID Tuning
Tune the active mode’s steering correction gains and timing safeguards.

    
Driving safety: PID edits are applied to the live controller and reset its accumulated PID state. Adjust while stationary or with the wheels safely lifted, and tune gradually.

    

      
      

        
        
        
        
        
        
        
        
Output correction limits

      

      
      
KP/KI/KD are P/I/D gains. KT is the nominal controller sample period. Minimum/maximum dt protect calculations when frames stall or arrive too quickly. Derivative smoothing controls how much of the new derivative is used. Output limits cap the correction before servo-angle clamping. Each mode stores its own PID settings in its JSON file.
