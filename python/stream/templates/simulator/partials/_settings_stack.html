AVIS · Staged obstacle lane change Enabled by default

Default: average the latest 10 lane-controller commands and begin the right-return maneuver when the mean enters −10% to +10% AVIS steering. The sample window and band can be changed below. The passing-lane hold remains the minimum time.

The bypass controller re-arms only after the configured number of consecutive front readings exceed “Path clear above”. A missing/invalid front reading brakes immediately; the Engine is disarmed only if the telemetry outage lasts longer than the configured grace period. A confirmed near obstacle still causes an immediate Engine stop.

AVIS uses direct left steering → left ROI lock → lane-following pass → direct right steering → right ROI lock. The independent forward guard always brakes at the configured threshold (at least 20 cm) and on every missing/invalid front sample. A short telemetry gap no longer closes the Engine session; a sustained outage beyond the grace setting does. Left and right direct steering are configured independently in AVIS percent; the global steering limit still bounds the command. Three range rays are not a 2D occupancy map; test at minimum speed and retain supervision.

PID steering controller Shared City / Race

The simulator can use the same PID steering correction as City and Race: the lane-centering error is fed through P, I and D gains before the virtual servo angle is normalized for AVIS or CARLA. Disable PID to use the vision processor's direct steering estimate.

Defaults match the City/Race Stream controller: KP 0.35, KI 0, KD 0.01, KT 0.01 s, output limits −80…+80°, minimum/maximum sample interval 0.001/0.2 s and derivative filter 0.25. Changes apply to the virtual controller while the simulator is running and are stored in this mode's .sim.json profile.

Integration notes

What the adapter abstracts away

Vision: {{ caps.vision_profile|capitalize }} image processing is reused directly; the camera source changes, not the algorithm.

Actuators: there is no hardware serial channel here. Structured simulator actuator events are shown in the virtual console. {% if caps.simulator_backend == 'avis' %}Steering uses the legacy signed −100..100 protocol; speed uses 0..100 percent.{% endif %}

Encoder: pulse count/distance are estimated from simulator movement, not treated as a hardware-grade measurement.

Restart: {% if caps.simulator_backend == 'avis' %}Host, port and TCP timeout are saved in this AVIS mode's profile; reconnect the AVIS TCP session after changing connection details.{% else %}Host/port, vehicle blueprint and sensor geometry changes are persisted in a mode-specific file, but require a restart to reconnect/recreate actors.{% endif %}
