Integration notes

What the adapter abstracts away

Vision: {{ caps.vision_profile|capitalize }} image processing is reused directly; the camera source changes, not the algorithm.

Arduino: there is no hardware serial channel here. Structured simulator actuator events are shown in the virtual console.

Encoder: pulse count/distance are estimated from simulator movement, not treated as a hardware-grade measurement.

Restart: host/port, CARLA vehicle blueprint and sensor geometry changes are persisted in a mode-specific file, but require a restart to reconnect/recreate actors.
